# Go code

Prefix: GO.

- **GO1:** `make lint` must pass with zero issues. It fails on any `go fix -diff ./...` suggestion, then runs golangci-lint v2 with the linters in `.golangci.yml` (among them `err113`, `wrapcheck`, `wsl_v5`, `nlreturn`, `lll`, `mnd`, `gochecknoglobals`, `ireturn`, `depguard`, plus the `gci`, `gofumpt` and `goimports` formatters). Test files are excluded from linting by `.golangci.yml`, not from review.
- **GO2:** Imports are limited by `depguard` to the standard library, `github.com/psyb0t/...` and `github.com/stretchr/testify`. The only runtime dependency is `github.com/psyb0t/ctxerrors`, and the README and docs say so. Adding another one is a design change, not a convenience.
- **GO3:** Wrap returned errors with `ctxerrors.Wrap` or `Wrapf` and a short action phrase, as `handlers.New` does ("build stdout handler"). A caller-checkable failure gets an exported sentinel in the package's `errors.go` (`ErrInvalidLogLevel`, `ErrInvalidFormat`), wrapped so `errors.Is` matches it.
- **GO4:** A `//nolint` names the linter and gives the reason on the same line, as in `handlers/loki/loki.go` (`//nolint:contextcheck // a slog.Handler has no parent ctx to inherit`). The one `init` in `slogconf/log.go` is the module's reason to exist and carries `//nolint:gochecknoinits`; do not add another.
- **GO5:** Repeated strings and numbers are named constants (`pushPath`, `httpTimeout`, `DefaultSearchLimit`, `outputSlot`). Environment variable names are exported constants (`slogconf.EnvVarNameLevel`, `loki.EnvVarNameURL`) so callers and tests use the same name.
- **GO6:** `vendor/` is generated by `make dep`. After a `go.mod` change, run `make dep` and commit `go.mod`, `go.sum` and `vendor/` together. Never edit files under `vendor/`.
- **GO7:** Doc comments say why, and they name current identifiers. A rename updates every comment and doc that mentions the old name.
